# Source Policy

Allowed sources:

- official SDK/network endpoint documentation
- domains observed in our own device/browser testing
- user reports with reproducible examples
- public security advisories that permit factual use
- public filter projects only for category research and false-positive analysis

Disallowed sources:

- bulk copying from third-party filter lists
- mechanically converting third-party filter syntax into this project
- mirroring third-party feeds under our own URL
- copying third-party comments or metadata

Every accepted rule should be explainable without relying on a copied source.
